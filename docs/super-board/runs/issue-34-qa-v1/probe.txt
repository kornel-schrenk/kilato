Screenshots use labelled stub tiles, z/x/y, because tests never call OpenStreetMap.
Each read is QA's own, not lineOnMap: it walks the real SVG path of the 1 km circle at 720 points, in percent of them.
- inWindow: inside the browser window
- onMap: inside the map, which is what AC4's page test counts
- unCovered: inside the map, with the map itself owning that pixel
- coveredBy: what sits on the rest of the map's share of the line
- radiusPx: half the width of the circle. The spec says 310 px at zoom 15 and 155 px at zoom 14
All 23 probes pass on the head. A first run failed one, and it was my mistake: the probe read the pin's place once, before the drag ended and the pin moved. With a poll, as the page tests do, it passes. These numbers are from that run.
